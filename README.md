# T-Bank
Приложение созданно для работы с банком.  нём можно смотреть
траты по заднной дате, список трат по картам и категориям.
Также можно вывести курсы акций и валют, заданные в настройках
пользователем. 

Для корректной работы нужно вставить свой API-key в соответсвующем файле.

Приложение работает с json- и xlsx-файлами.
